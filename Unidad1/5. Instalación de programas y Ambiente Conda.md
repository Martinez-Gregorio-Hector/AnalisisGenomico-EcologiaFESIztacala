Que realiza este tutorial
Primero epezaremos por revisar el estado de conda o miniconda, asi como la instalacion de los paquetes y las versiones Segundo instalaremos las ultimas versiones de los programas FASTQC, HISAT2 y SAMtools De forma implicita veremos como hacer ejecutable un script y como navegar por la termial

Para empezar vemos que version de conda y miniconda tenemos:

corremos la siguiente linea en la terminal, solo copiar y pegar lo que esta despues de el $

$ conda info
si conda y miniconda esta instalado debes poder ver algo como lo anterior, aqui podras ver las rutas asi como la version de conda/miniconda y phyton, en este caso tengo la version 25.1.1 (el 25 es por el año) de conda/miniconda y la version 3.12.2 de phyton, si tienes una version de conda del 24 o anterior es mejor que la actualices.

Para actualizar o instalar conda solo corre las siguientes lineas

solo abre la terminar de linux, despues copia y pega las siguientes lineas descarga las carpetas para insatalar conda

$ wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash es para ejecutar un script y debes estar en la capeta donde esta el script de lo contrario no funciona por lo general solo debes ejecutar la linea, pero si no te deja debes averiguar donde esta

$ bash ~/Miniconda3-latest-Linux-x86_64.sh
tu debes decirle si a todo y se instalara sin problema una ves te salga un mensaje de que se instalo de forma correcta debes refrescar tu sesion y en teoria tendras conda instalado

$ source ~/.bashrc
vuelve a despligar la informacion y checa las versiones

$ conda info
Ahora, vamos a crear un entorno de conda con una version resiente de phyton, esto es mejor que instalar phyton o alguna otra cosa como usar contenedores o cosas asi

$ conda create –name python_sergio python=3.13.2
Para activar tu ambiente con la ultima version de phyton solo usa lo siguiente

$ conda activate python_sergio
te debe salir entre parentesis (python_sergio) y despues el nommbre de tu usuario

Una vez que tengas conda/miniconda instalado es muy facil instalar paquetes, solo debes correr lineas muy simples. En lo personal no checo si esta instalado un programa, solo lo vuelvo a instalar, esto igual fuciona cuando hay errores

solo copia y pega las siguientes lineas en la terminar de linux, una a la vez si necesitas algun paquete ademas de los tres que mencione al inicio solo ve a este enlace y teclea el nombre del paquete https://anaconda.org/bioconda

$ conda install bioconda::fastqc
$ conda install bioconda::hisat2
$ conda install bioconda::samtools
ahora vemos las versiones

$ fastqc –version
$ hisat2 –version
$ samtools –version
Pues en teoria ya esta todo listo paea correr tus scripts y hacer analis. Veamos como hacer un script y hacerlo ejecutable

Si has llegado hasta ya te habras dado cuenta que un poco de la sintaxis de linux, lo que hay que resaltar es que siempre se incia con el nombre del programa/paquete y despues debes poner las funciones (las personas tambien le llaman flags) que debe ejecutar el programa, por decir, si solo pones samtools te despliega una parte del manual, pero si le agregas –version (siempre todas la funciones empiezan con –) realiza una tarea diferente, incluso samtools te dice como usarlo: samtools [options] La parte de [options] son valores que debes poner para ajustar los parametros de la tare, pueden ser valores numericos o directorios para guardar tu archivo

pero hagamos un script

de forma general los scripts son arhivos de texto plano (txt) con terminacion .sh nano crea archivos con terminacion .sh

$ nano mi_script.sh #solo modifica la parte de mi_script por lo que quieras
esto te desplegara una pantalla negra y para hacer ejecutable un script debes agregar lo siguiente:

” #!/bin/bash” pero sin las comillas y despues tu texto ” samtools –version”

“#!/bin/bash” es la parte mas importante para que se ejecuten los scripts y deben ir al inicio de todos

Despues de que agreges el contenido a tu scipt. teines que presionar “ctrl + x” , le daras a “y” y finalmente tendras que darle “Enter”

pues ya tienes tu script, para ejecutarlo solo debes darle un comando que ya has usado bash ~/Miniconda3-latest-Linux-x86_64.sh, solo que en tu caso es also asi:

$ bash ./mi_script.sh
Despues vemos como movernos entre directorios, cualquier pedo me dices.
